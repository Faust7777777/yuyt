# 心理中心预约小程序

这是我在 2025 年 12 月初做的一个微信小程序项目，服务的是学校心理中心的预约场景。

它要解决的问题并不玄。以前的预约主要靠人工沟通，信息散在线下，确认靠来回问，排期靠手动对，流程长，协调慢，隐私也难顾周全。我接手这件事时，目标很直接：把原本靠人一条条接住的流程，收成一套能自己跑起来的系统，让学生更快完成预约，也让老师和学生助理少耗在反复确认上。

## 项目起因

这个项目由我独立策划、独立开发。现在回头看，它其实很像我后来理解的产品工作：先不是急着写页面，而是先把问题拆开，看清楚谁在用、卡在哪、什么动作必须留、什么动作可以省。

我当时盯住的是两类人。

- 对学生来说，预约入口要清楚，流程要短，最好不要把一次心理预约做成一张冷冰冰的表单。
- 对心理中心来说，排班、协调、统计这些重复工作要尽量从人手里挪开，不然人数一多，事情一碎，最后谁都累。

所以我把业务流程压成了几步：

1. 教师先设置本周可预约时间。
2. 学生用学号和手机号登录。
3. 学生按时间段查看可预约教师并完成预约。
4. 教师端查看预约记录，系统按周归档并重置当周数据。

这套逻辑不复杂，但很实用。它借了学校课表和选课系统那种“先放时段、再按时段选择”的思路，把线下零散沟通变成了可追踪、可复用、可维护的流程。

## 我是怎么把它做出来的

这不是一个“顺手就写完”的项目。对当时的我来说，它还是第一次把我从“写页面”这件事里拽出来，让我真正碰到页面背后的东西。

那时我主要还是靠 chatbot 协助开发，工具的上下文记忆远没有现在稳定。为了少返工，我自己先整理了一份很细的项目结构树，再写提示词约束它在改代码前先回顾结构，记忆模糊时先提问，再继续生成。即便如此，开发过程里还是经常顾此失彼。也正是因为这些磕碰，我第一次真正意识到：需求、结构和边界如果不先立住，后面每一步都会很费劲。

部署上我也走过弯路。一开始我尝试过 `Vercel`，思路很自然，先把服务挂起来，再接微信小程序前端。后来发现微信小程序的访问链路并不适合这种方案，数据请求经常出问题，看着像代码错了，根子其实在部署方式上。后面我切到微信云函数，把调用、数据库和环境都放回微信云开发体系里，事情一下顺了很多，工作量降了，后期维护和成本压力也跟着降了。

如果说这个项目给我留下了什么，那不是“我做了一个小程序”这么简单。它更像是我理解前后端、部署、数据结构、运行成本这些事情的起点。也是从这里开始，我越来越在意需求定义、目标拆解和流程设计，后来会想走产品经理这条路，和这次经历关系很大。

## 结果

下面这些数据，来自项目落地后的实际使用反馈与统计。

- 平均预约时间节省约 `70%`
- 长期协调工作减少了约 `2` 名学生助理的人力占用
- 后续这套流程又扩展到了辅导员谈话预约场景
- 在后续场景里，协调工作时间进一步减少了约 `90%`

我一直把这些结果留着。因为它们说明，这个项目不是停在页面层面的练手作品，它确实替掉了一部分原本只能靠人工硬撑的流程。

## 技术结构

技术上，这个项目并不追求复杂，而是追求够用、稳定、能落地。

- 前端：微信小程序
- 后端：微信云函数
- 数据存储：微信云开发数据库
- 部署与调试：微信开发者工具

当前主要数据集合如下。

- `users`：教师账号信息
- `students`：学生登录信息
- `schedules`：教师可预约时间
- `appointments`：当前周预约记录
- `appointment_logs`：归档后的历史预约记录

## 项目结构

```text
miniprogram/
  app.js
  app.json
  pages/
    login/                         登录页
    student/schedule/              学生预约页
    teacher/teacher-schedule/      教师排班页
    teacher/teacher-appointments/  教师预约记录页
  config/
    time-slots.js                  教师预约记录页使用的时间段配置
  utils/
    api.js                         小程序侧云函数调用封装
    config.js                      时间段和教师示例配置

cloudfunctions/
  login/                           教师登录
  studentLogin/                    学生登录
  schedule/                        教师排班读写
  appointment/                     预约、取消、查询
  weeklyReset/                     每周归档与重置
```

## 本地运行

1. 用微信开发者工具打开项目根目录。
2. 创建或绑定自己的云开发环境。
3. 上传并部署 `cloudfunctions` 下的业务云函数。
4. 在云数据库中初始化集合和教师账号数据。
5. 编译小程序，在模拟器或真机中调试。
